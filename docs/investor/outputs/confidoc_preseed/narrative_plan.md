# Narrative plan — ConfiDoc pre-seed deck

Audience: pre-seed investors, cyber/AI angels, Bpifrance-style financing contacts.

Objective: reposition ConfiDoc from privacy document processing to a fundable Secure AI
Chat wedge, then show a credible expansion path toward AI agent security.

Narrative arc:

1. The highest-value documents cannot safely go into AI.
2. ConfiDoc creates an IA-safe version and lets users chat only on that version.
3. The product is already built enough to demo.
4. The wedge is narrow enough to sell, while the agent-security vision is large enough
   for venture scale.
5. The pre-seed finances pilots, GTM, product hardening and proof of demand.

Slide list:

1. Title and positioning.
2. Problem.
3. Why now.
4. Solution.
5. Product modules.
6. Demo flow.
7. Product status.
8. Market wedge and expansion.
9. Business model.
10. Defensibility.
11. Traction to prove.
12. Raise.

Visual system:

Dark enterprise security palette; green/teal for safe data, blue for AI workflow, amber
for risk, red for blocked leakage. Dense but readable B2B cyber/SaaS style. Use editable
PowerPoint text, shapes, tables and diagrams so the founder can revise quickly.

Source plan:

- Internal repo product facts from README and docs/investor.
- Current public standards and market validation already researched: OWASP Agentic Top
  10, MCP security guidance, NIST AI RMF GenAI profile, recent AI agent security funding.

Editability plan:

All slide copy, labels, cards, process diagrams and metric placeholders are editable.
No investor-critical text should be embedded in raster imagery.
